# 🎓 Ollama + Streamlit AI Study Assistant

A simple local AI study assistant built using **Streamlit** and **Ollama** with the **Qwen3 4B** language model.

The application allows users to enter questions or prompts and receive AI-generated responses through a simple web interface.

## 🚀 Features

- Simple Streamlit web interface
- Local AI processing using Ollama
- Powered by Qwen3 4B
- Conversation history
- Clear conversation option
- Study-focused AI responses
- No external API key required

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Qwen3 4B

## 📋 Requirements

Before running the application, make sure you have:

- Python installed
- Ollama installed
- Qwen3 4B model downloaded
